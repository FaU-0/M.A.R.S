# Документация M.A.R.S.

**M.A.R.S. (Mobility & Asymmetry Reporting Sessions)** — система дистанционного приёма пациентов с параличом лицевого нерва и после операций на лице. Врач и пациент общаются по видеосвязи. Система:
- измеряет асимметрию и подвижность лица;
- расшифровывает и обезличивает разговор;
- формирует отчёт и заключение.

Всё работает в локальной сети клиники, без облачных сервисов.

Схемы в документации написаны на [Mermaid](https://mermaid.js.org/) и отображаются прямо на GitHub. Графики лежат в `docs/img/` и пересобираются из сохранённых результатов замеров командой `python3 docs/make_charts.py`.

## Коротко о главном

| | |
|---|---|
| Сервисы | 6: gateway, database, vision, speech, assistant, reports |
| Технологии | Python (стандартная библиотека), SQLite, WebRTC, MediaPipe Face Landmarker, Whisper (faster-whisper), Ollama `qwen2.5:3b` |
| Где анализируется лицо | В браузере пациента: видео не покидает устройство |
| Нагрузка | Видеоприём — 16 пар без ошибок; расшифровка речи вовремя — 2 пары (Python 3.14 без GIL) |
| Точность | Повторяемость MDC95 0,1–0,5 мм; на клиническом наборе MEEI сторона паралича определяется верно в 82 % случаев, ρ = 0,83 с оценкой врача |
| Качество | 18 наборов автотестов, CI с Docker-сборкой |
